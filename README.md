# Kampala Reels: offline 3D reel maker (Android)

Native Kotlin + Compose + Filament + MediaCodec + Media3 Transformer. 100% offline, no accounts.

## Features
- 9:16 live preview (540x960) and 1080x1920 H.264 export to Movies/KampalaReels
- 3 bundled low-poly environments (Kampala street, Nakasero, Busega junction), generated by `tools/gen_set.py`
- Import: .glb avatar, photo -> cutout standee (offline ML Kit), environment packs (.zip)
- Timeline: camera presets, timed text overlays, length 5-60s, auto-save
- MP3 soundtrack + "Auto-cut camera to beats" (offline beat detection)
- Foreground service, cancel button, low-memory warning

## Build (GitHub Actions)
Push to `main`. Download the `kampala-reels-apks` artifact. Debug APK always; signed release APK if you add repo secrets
`KEYSTORE_B64` (base64 of your .jks), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
Create a keystore: `keytool -genkey -v -keystore release.jks -alias reels -keyalg RSA -keysize 2048 -validity 10000`, then `base64 -w0 release.jks`.

## Environment packs (.zip, flat)
`set.glb` (optional geometry), `env.json` (optional `{"sky":[r,g,b],"ambient":[r,g,b]}`), and for HDRI lighting `ibl.ktx` + `sky.ktx`
(made with Filament `cmgen --format=ktx --deploy=out/ photo.hdr`). With no KTX files the app uses a flat sky colour + constant ambient light.

## Structure
```
model/    ReelSpec, CameraPresets, ProjectStore
assets/   AssetManager (imports, memory caps), PhotoAvatar
audio/    BeatAnalyzer
render/   ReelRenderer (single render thread owns Filament)
export/   ExportEngine (pass 1 MediaCodec, pass 2 Media3: text + MP3 -> AAC + mux)
service/  KeepAliveService
ui/       EditorScreen, EditorState, ReelCanvas
```

## Test checklist (first device run)
1. CI green? If not, paste the log; expect small Filament/Media3 API renames.
2. App opens, preview shows the street scene. If it is too dark/bright, tune `intensity` values in `ReelRenderer.kt`.
3. Export 10s with no music, then with MP3 + text. Check the gallery video plays at the right speed.
4. Import a .glb, then a selfie; check scale and facing.
5. Cancel mid-export; confirm no crash and the next export works.
